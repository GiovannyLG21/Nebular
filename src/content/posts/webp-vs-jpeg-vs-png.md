# Common Image Formats

- **JPEG**: Best for photographs, balanced size and quality
- **PNG**: For images needing transparency or sharp edges
- **WebP**: Modern format with superior compression for web

# Performance Impact

Choosing the right format can drastically improve load times. WebP offers smaller file sizes for most cases, but verify compatibility for your users before adopting site-wide.
