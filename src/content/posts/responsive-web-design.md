# Why Responsive Design Matters

Responsive web design ensures your website looks great and functions well on all devices, from large desktops to smartphones. It’s a must for modern web development.

# Techniques

- Use flexible grid layouts
- Apply media queries for breakpoints
- Set images to max-width: 100%

# Example Media Query

```css
@media (max-width: 600px) {
  .container { flex-direction: column; }
}
```

A responsive approach increases usability and reaches a wider audience.
